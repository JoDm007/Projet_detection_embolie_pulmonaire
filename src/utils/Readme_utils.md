# 📌 Package Utils : Utilitaires Transversaux

## 💡 Le Package Utils en 2 Mots (Pour tous)

Le package **Utils** rassemble les **outils partagés et réutilisables** par l'ensemble des modules (O1 à O8) : gestion uniforme des journaux d'exécution (logs), sauvegarde/lecture optimisée des fichiers 3D, et fonctions utilitaires de visualisation.
